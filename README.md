# موقع الإنجاز لصيانة السيارات الألمانية والأوروبية

موقع عربي/إنجليزي ثابت، بلا إطار عمل أو خطوة بناء. افتح `index.html` مباشرة أو شغّله عبر أي خادم ملفات ثابت.

## البيانات

كل بيانات النشاط موجودة في `js/data.js` فقط. من هناك يمكنك تعديل الهاتف، حالة دعم واتساب، العنوان، التقييم، عدد المراجعات، ساعات العمل، الخدمات والماركات.

- `verified: true` يعني أن المعلومة جاءت ضمن البيانات المؤكدة المقدمة للمشروع.
- `verified: false` يعني أنها تحتاج مراجعة من صاحب المركز قبل النشر.
- دعم WhatsApp مفعّل على الرقم المزوّد من ملف النشاط.
- تقييم Google الحالي 4.1 من 99 مراجعة، ويمكن تحديثه مركزيًا من `data.js`.

## الصور والمراجعات

أضيفت الصور الرسمية المختارة والمحسنة بصيغة WebP داخل `assets/images/workshop/`، مع تحميل كسول للمعرض وصورة Hero محسنة.

الصور الرسمية موجودة داخل `assets/images/workshop/`. أضيفت 8 مراجعات Google عامة منتقاة إلى `reviews` في `data.js`، ويمكن إضافة المزيد بالبنية نفسها مع إبقاء `verified: true` للمراجعات المنقولة من المصدر فقط.

## النشر

يمكن رفع المجلد كما هو إلى GitHub Pages أو Netlify أو Vercel أو Cloudflare Pages. قبل النشر:

1. استبدل `https://example.com/` في `index.html` و`robots.txt` و`sitemap.xml` بالنطاق الحقيقي.
2. أكّد الإحداثيات والخدمات والماركات وواتساب وساعات الجمعة.
3. أضف الصور الرسمية ووسم Open Graph للصورة.
4. راجع سياسة الخصوصية مع الجهة المالكة.

## مصادر الشعارات

ملفات الشعارات المحلية في `assets/logo/brands/` مأخوذة من صفحات ملفات Wikimedia Commons الخاصة بـ BMW وMercedes-Benz وAudi وPorsche وMINI وLand Rover. العلامات التجارية مملوكة لأصحابها وتُستخدم هنا فقط للدلالة على أنواع السيارات المخدّمة.

## الترجمة

النصوص العامة في `js/translations.js`. يبدّل الزر اللغة دون إعادة تحميل ويحفظ الاختيار محليًا.
